# Personal portfolio — draft

Open `index.html` locally to preview. This is a static one-page portfolio, ready for GitHub Pages once contact details and project links are updated.

## Before publishing
1. Replace `YOUR_EMAIL_HERE` with your email address.
2. Confirm project descriptions and your personal contributions to team projects.
3. Add individual repository links after uploading the projects.
4. Add a downloadable CV if you want it public (remove personal phone if privacy matters).
5. Publish via GitHub Pages: create a repository, push this `index.html`, then enable Pages under Settings → Pages.

The security door project is a frontend-only prototype with sample data, not a real deployed access-control system.
